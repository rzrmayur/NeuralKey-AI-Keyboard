NeuralKey prediction language model
===================================

english_lm.dict and english_bigrams.dict are generated by tools/build_language_model.py. They contain only
derived, aggregated word-frequency scores and the most likely next words for each word; no raw corpus text.

Sources
-------
1. Word and word-pair frequency counts: Peter Norvig, "Natural Language Corpus Data: Beautiful Data"
   (https://norvig.com/ngrams/), derived from the Google Web Trillion Word Corpus (Brants & Franz),
   distributed by the Linguistic Data Consortium. Norvig's accompanying code is MIT licensed.

2. Spelling filter, capitalisation hints and offensive-word flags: the English (US) word list from the
   Android Open Source Project LatinIME keyboard (platform/packages/inputmethods/LatinIME), licensed under
   the Apache License, Version 2.0 (http://www.apache.org/licenses/LICENSE-2.0).
   "Includes Dictionaries (c) Lexiteria LLC. Used by permission." (as stated in the AOSP NOTICE file)

3. Spelling filter: the SCOWL / Hunspell en_US dictionary already bundled in this app
   (see english-dictionary.txt).
