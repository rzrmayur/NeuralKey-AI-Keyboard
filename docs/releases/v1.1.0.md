Fixes keyboard layout and touch handling around Samsung/Android system keyboard controls, and adds offline English typing assistance.

### Layout and input fixes
- Reserve remaining navigation-bar, caption-bar and side cutout insets instead of drawing keys behind system controls.
- Restore Android's normal IME touch region so system keyboard controls remain usable.
- Keep AI panels and the typing surface at a consistent height; disable fullscreen takeover in landscape.
- Add an accessible Hide keyboard button and a keyboard-picker fallback.
- Stop held backspace and pressed-key state when touches are cancelled or the view changes.
- Bound long model/spacebar labels and keep the physical QWERTY grid left to right.
- Handle selected-text deletion, surrogate-pair emoji deletion, editor Enter actions, one-shot Shift and double-tap Caps Lock.

### Suggestions and autocorrection
- Bundled SCOWL English dictionary with over 100,000 words and inflections. No account, API request or dictionary download is needed.
- Tap a word in the suggestion strip to complete/replace the current word.
- Conservative correction on space; immediately press Backspace to restore the original spelling.
- Separate Word suggestions and Autocorrect on space switches under Preferences.
- Suggestions/corrections respect passwords, email/URL/numeric/phone fields and apps' no-suggestions flags. Names and ambiguous corrections stay under user control.
- Typing assistance currently supports English. Other languages can be typed with autocorrection switched off.

### Reliability and privacy
- Clear drafts and cancel AI requests when changing input fields; never extract password drafts for AI.
- Reject applying an AI result after its source draft changes; show API failures as errors instead of inserting them into output.
- Remove plaintext API-key-storage fallback and exclude app data from backup/transfer.

### Validation
CI runs unit regressions, Android/Compose layout and touch-cancellation checks, Android lint, and an APK build. Automated tests simulate portrait, narrow-screen and landscape layouts, plus bottom and side system insets. Physical Samsung One UI testing remains necessary; an S22 is not connected to the build environment.

### Installation / signing
Download `NeuralKey-AI-Keyboard-v1.1.0.apk`. This is a **debug-signed development APK**, matching the project's current sideload/testing stage. The original signing key was not present in the repository. If Android reports a conflicting signature, uninstall v1.0.0 first, then install this APK and re-enable/select NeuralKey. Uninstalling clears its saved settings/API key. A persistent private release signing key is required before production distribution and reliable future in-place updates.

`SHA256SUMS.txt` contains the APK checksum. Dictionary attribution and redistribution notices are bundled in `assets/licenses/english-dictionary.txt`.
