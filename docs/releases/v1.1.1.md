Follow-up to the Samsung S22 report: the empty area above the letters and bottom keys overlapping the system keyboard-switch/hide controls, especially on first opening in WhatsApp.

### Changes
- Replace the separate, always-empty suggestion strip with one 48dp toolbar. Suggestions appear between the AI and Hide buttons while typing, without moving the keys. The model selector returns when there are no suggestions.
- Move system spacing to a native input-view container. Refresh it when the view attaches, becomes visible, starts an input session and the IME window opens.
- Reconcile the real window's navigation, IME caption-bar and cutout insets before drawing. Delayed or consumed child insets no longer need an AI/keyboard toggle to trigger layout; space already reserved by Android is subtracted to avoid double padding.
- Keep the bottom system-control area outside key hit targets, and keep Android's own navigation controls and IME touch-region handling.
- Retain offline English suggestions, autocorrection with Backspace undo, privacy protections and cancellation-safe key handling from v1.1.0.

### Validation
CI runs the full editing/dictionary tests, Compose toolbar/layout/gesture checks, native View inset tests on Android API 30 and 35, Android lint and an APK build. New cases cover delayed caption-bar delivery without a Compose state change, consumed/partially reserved insets, repeated inset changes, side cutouts, control-area touch isolation and suggestions that do not shift the keys.

Physical Samsung One UI testing remains unverified. On the S22, check opening directly in WhatsApp, switching between WhatsApp and Chrome, closing/reopening the keyboard, and rotating the phone. The bottom row should remain above the system keyboard/hide buttons without opening AI first.

### Installation
Download `NeuralKey-AI-Keyboard-v1.1.1.apk`. This remains a **debug-signed development APK**. The previous CI signing key is not stored in the repository, so Android may reject an in-place update with a signature conflict. If that happens, uninstall the previous NeuralKey APK, install this one, then re-enable/select the keyboard. **Uninstalling clears NeuralKey settings and its saved API key.**

`SHA256SUMS.txt` contains the APK checksum. A persistent private signing key is still needed for reliable future in-place updates.
